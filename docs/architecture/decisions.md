> Trasladado tal cual desde `CLAUDE.md` §7 el 2026-10-24 para que `CLAUDE.md` siga siendo legible en cada sesión. **Es la misma fuente de verdad:** las decisiones 001–072 están vigentes salvo que se marquen como sustituidas, y el código las cita por su número.
>
> **Reglas del registro:** una fila por decisión nueva o modificada; **nunca se borran filas**: si una decisión cambia, se marca como sustituida y se añade otra. Las decisiones **propuestas** (estado «Propuesta») no entran en vigor hasta que el usuario las apruebe; al aprobarlas se cambia su estado a «Aprobada» con la fecha.
